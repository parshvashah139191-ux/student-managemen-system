# Student Management System

## Advanced Java Technology – Mini Project

### Project Overview
A Java-based application designed to manage student records efficiently using database connectivity and web technologies.

### Technologies Used
- Java
- JDBC
- Servlet
- JSP
- Swing
- Spring Framework
- Hibernate ORM
- MySQL
- Apache Tomcat
- Maven
- NetBeans IDE

### Project Features
- Student record management
- Add, view, update and delete students
- User authentication
- Session management
- Database connectivity
- Form validation
- Exception handling

### How to Run
1. Download or clone this repository.
2. Open the project in NetBeans.
3. Start MySQL using XAMPP.
4. Create the student_db database.
5. Import student_db.sql using phpMyAdmin.
6. Configure database credentials locally.
7. Configure Apache Tomcat in NetBeans.
8. Clean and build the Maven project.
9. Run the project using Apache Tomcat.

### Project Purpose
Developed as an academic mini-project for Advanced Java Technology (AJT).
